VowPic 是海外响应式 Web SaaS。当前执行只以以下文档为准：

1. `docs/PRD.md`：产品范围、用户流程和验收口径。
2. `docs/superpowers/specs/2026-07-10-vowpic-commercial-closure-design.md`：获批商业闭环设计。
3. `docs/superpowers/plans/2026-07-10-vowpic-commercial-closure-implementation.md`：分阶段实施与真实验收计划。
4. `docs/ARCHITECTURE.md`：Web、API、Worker、数据和外部服务边界。
5. `docs/SECURITY.md`：身份、权限、媒体、支付、Provider 和密钥边界。
6. `docs/OPERATIONS_RUNBOOK.md`：Preview、发布、迁移、回滚和事故处理。
7. `docs/PRODUCTION_ACCEPTANCE.md`：当前生产验收状态和证据要求。
8. `docs/operations/risk-lockdown-runbook.md`：安全基线和受保护发布细节。
9. `docs/ai-worklog.md`：已经执行的修改、验证结果和外部 `NOT_RUN` 项。

历史文件只用于追溯，不能提供当前命令、配置或 PASS 证据。未运行的真实外部链路必须保持 `NOT_RUN`；本地测试、普通 Vercel Preview 或 UI 可打开都不等于 `Production accepted`。
