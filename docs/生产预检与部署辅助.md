# 生产预检与部署辅助

## 目标

在真正做公网联调之前，用统一脚本先确认：

- 商用严格模式配置是否完整
- 数据库 / Redis / 队列 / ComfyUI / 存储 / 支付配置是否齐备
- 当前阻塞项到底是代码问题还是外部基础设施问题

## 推荐命令

### 1. 低风险预检

```bash
python backend/scripts/preflight_production.py --write-artifacts
```

作用：

- 不做真实存储写删
- 输出可读控制台摘要
- 同时生成：
  - `backend/artifacts/production_preflight.json`
  - `backend/artifacts/production_preflight.md`

### 2. 含真实存储探针的预检

```bash
python backend/scripts/preflight_production.py --probe-storage --write-artifacts
```

作用：

- 除基础就绪检查外，再执行一次真实上传 / 删除探针
- 适合正式联调前最后一轮确认

### 3. Windows 包装命令

```powershell
cd backend
powershell -ExecutionPolicy Bypass -File scripts/run_preflight.ps1
```

可选参数：

- `-NonStrict`
- `-NoProbeStorage`
- `-NoArtifacts`
