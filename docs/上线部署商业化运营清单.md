## 上线前必须完成

1. 数据库
   - 使用 Supabase / Neon / 托管 Postgres。
   - 配置 `DATABASE_URL`。
   - 执行 `cd backend && python scripts/migrate_db.py`。
   - 生产保持 `AUTO_CREATE_TABLES=false`。

2. 存储
   - Vercel 部署优先使用 Vercel Blob：`STORAGE_PROVIDER=vercel`、`BLOB_READ_WRITE_TOKEN`。
   - 非 Vercel 可使用 S3：配置 `AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY`、`AWS_S3_BUCKET`、`AWS_REGION`。

3. 生成与质检
   - `GENERATION_ENGINE=wenwen` 时必须确认 Wenwen key 有图片生成和视觉质检权限。
   - `QA_REQUIRE_VISION=true`，生产不要关闭。
   - `WENWEN_MAX_RETRIES` 建议设为 `1` 或 `2`，质检失败可自动重试。

4. 支付
   - 配置 Creem API key、webhook secret、3 个积分包 product id。
   - 在 Creem 后台配置 webhook 到：`https://你的域名/api/v1/payments/webhook`。
   - 支付前必须配置 `SUPPORT_CONTACT_EMAIL` 或 `SUPPORT_CONTACT_URL`。

5. 风控
   - `RATE_LIMIT_ENABLED=true`。
   - 建议默认：
     - `NEW_ACCOUNT_IP_LIMIT_PER_HOUR=8`
     - `NEW_ACCOUNT_DEVICE_LIMIT_PER_HOUR=3`
     - `TRIAL_WELCOME_CREDITS=2`
     - `TRIAL_DAILY_GENERATION_LIMIT=3`

6. 自动清理
   - 配置 `CRON_SECRET` 或 `CLEANUP_CRON_TOKEN`。
   - Vercel cron 已指向 `/api/v1/ops/cleanup_expired_assets`。

7. 域名
   - `FRONTEND_BASE_URL=https://你的域名`
   - `WEBHOOK_BASE_URL=https://你的域名`
   - `CORS_ALLOW_ORIGINS=https://你的域名`
